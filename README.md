# Tracker-Habit

A simple habit tracker web app for building and maintaining daily routines.

## Tech stack

- **React 19** with **TypeScript**
- **Vite** for the dev server and build
- **Tailwind CSS** for styling
- **React Router** for navigation
- **Recharts** for progress visualizations
- **oxlint** for linting

## Getting started

```bash
# Install dependencies
npm install

# Start the dev server
npm run dev

# Build for production
npm run build

# Lint
npm run lint
```

The dev server runs on the port Vite reports in the terminal (default `http://localhost:5173`).
